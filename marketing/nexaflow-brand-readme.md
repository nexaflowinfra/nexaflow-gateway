# NexaFlow Brand Assets

## Direction
NexaFlow should feel like a simple, serious AI business operating system rather than a single enquiry tool.

The brand direction is:
- black, white, and grey first
- small green accent only when needed
- minimal, technical, calm, and trustworthy
- ecosystem-focused: one core infrastructure powering multiple products

## Files
- `nexaflow-logo-mono.svg`: clean monochrome brand logo and wordmark.
- `nexaflow-logo-mono.png`: PNG export of the logo.
- `nexaflow-ecosystem-branding.svg`: ecosystem branding visual for decks, landing pages, or social posts.
- `nexaflow-ecosystem-branding.png`: PNG export of the ecosystem visual.

## Product Family
The NexaFlow core can later support:
- Enquiry
- CRM
- Billing
- Inventory
- Automation
- Dashboard

This keeps the brand broader than the first Enquiry product.
